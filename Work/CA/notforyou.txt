### 🟡 BLOCK 2: Memory Organization (Unit 4)
**Time: 4:00 PM - 6:00 PM**
*Why:* You said you couldn't find a good video. I will give you the simplified explanation right here. You don't need a video.

**1. Memory Hierarchy (The Pyramid)**
* **Task:** Draw a pyramid.
    * **Top (Fastest/Smallest/Expensive):** CPU Registers.
    * **Middle:** Cache Memory.
    * **Lower:** Main Memory (RAM).
    * **Bottom (Slowest/Biggest/Cheap):** Magnetic Disk (Hard Drive).
* **Concept:** "Locality of Reference" -> If I use data X, I will probably use data near X soon. So, move a chunk of data to Cache.

**2. Cache Mapping (The "Hard" Part made Easy)**
* Imagine **RAM** is a big library and **Cache** is your small desk.
* **Direct Mapping:** Book #1 from the library *must* go to Spot #1 on the desk. (Rigid, Fast collision).
* **Associative Mapping:** Book #1 can go *anywhere* on the desk. (Flexible, Hard to search).
* **Set-Associative:** The desk has "drawers" (Sets). Book #1 goes to Drawer A, but can be anywhere inside Drawer A. (Best of both worlds).

### 🔴 BLOCK 3: CPU & I/O (Unit 5)
**Time: 6:30 PM - 8:30 PM**
*Why:* This unit is full of easy "Difference Between" questions.

**1. RISC vs. CISC (Guaranteed Question)**
* **RISC (Reduced Instruction Set):** Simple instructions (1 cycle). Hard for humans, easy for machines. (Used in Phones).
* **CISC (Complex Instruction Set):** Complex instructions. Easy for humans, hard for hardware. (Used in Laptops).
* **Task:** Make a table with 4 points.

**2. DMA (Direct Memory Access)**
* **Concept:** The CPU is the Boss. Moving data from Hard Drive to RAM is boring work.
* **DMA Controller:** The Boss hires an Assistant (DMA). The CPU tells DMA: "Move 100 bytes from Disk to RAM," and then the CPU goes to do other work. DMA interrupts CPU when done.
* **Task:** Draw the block diagram: CPU, DMA Controller, Memory, I/O Devices connected by a bus.
